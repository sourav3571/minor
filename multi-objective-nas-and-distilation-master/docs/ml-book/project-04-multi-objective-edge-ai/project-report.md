# Project 4 report template

Define each objective, its direction, unit, artifact/runtime boundary, constraints, and measurement device. Include the hand-checkable illustrative example separately from actual measurements.

For measured candidates report validation accuracy, median/p95 latency and protocol, model artifact bytes/format, parameter count, and energy joules with power instrument/protocol—or `not measured`. Plot candidate trade-offs and state the objective directions used by Pareto selection. Explain feasibility and tie-breaking; report if no candidate satisfies constraints.

Discuss hardware dependence, FLOPs limitations, local-vs-edge scope, preprocessing inclusion/exclusion, and any export/quantization effects as separate ablations. Do not describe CPU results as physical edge-board measurements.
