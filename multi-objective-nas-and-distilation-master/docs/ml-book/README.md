# Hands-On Machine Learning: From First Principles to Edge NAS

This is a project-based textbook for building **Adaptive Teacher-Guided Multi-Objective Neural Architecture Search for Lightweight Edge Intelligence**. It follows the actual project brief: CIFAR-10/100, compact student CNNs, adaptive knowledge distillation, evolutionary architecture search, accuracy/latency/energy/model-size objectives, and real Raspberry Pi or Jetson evaluation.

## Environment

Use Python 3.11 in a virtual environment. Install the pinned package versions from [`requirements.txt`](requirements.txt):

```bash
python3 -m venv .venv
# Linux/macOS
source .venv/bin/activate
# Windows PowerShell: .venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Torchvision downloads datasets on first run. Check its dataset license/terms and keep the downloaded data local. For systems with a suitable accelerator, install the matching PyTorch build from the official PyTorch instructions and record the exact versions; do not assume CPU and GPU timing results are comparable.

## Honest measurement boundary

The code records validation accuracy, parameter count, serialized weight size, and repeated local inference latency. It does **not** pretend that CPU energy is a measurement of board energy. The problem brief calls for Raspberry Pi/Jetson tests and energy draw; report those only after measuring on that hardware with a stated power instrument/protocol. ONNX/TensorRT export is a deployment extension, not an automatically validated result. The textbook intentionally marks hardware-dependent results as `not measured` when the hardware is unavailable.

## Reproducibility rule

Never select a candidate, tune a threshold, or choose a checkpoint using the final test set. Search uses training and validation data; freeze the final choice and evaluate the test set once. Record seed, dataset split, code version, device, package versions, budgets, and raw candidate metrics. The book contains no invented experimental results: numeric candidate tables are explicitly illustrative unless generated by your run.
