# 2. Build the distillation loss carefully

## Two losses answer two questions

1. Cross-entropy (CE): does the student predict the ground-truth label?
2. Kullback–Leibler divergence (KL): how different is the student's softened distribution from the teacher's softened distribution?

For probability distributions `p` (teacher) and `q` (student), `KL(p||q)=sum_i p_i*ln(p_i/q_i)`. It is zero when distributions match and grows when the student assigns too little probability to teacher-supported classes. In PyTorch, `F.kl_div(input_log_probs, target_probs, reduction="batchmean")` expects student log-probabilities as `input` and teacher probabilities as `target`.

The objective is `total = alpha * CE + (1-alpha) * T^2 * KL`. Here `alpha` in `[0,1]` balances the ground-truth and teacher signals; `T` is temperature; `T^2` approximately compensates for gradients shrinking as logits are divided by T. At `alpha=1`, the objective is label-only training; at `alpha=0`, no direct CE term remains. Tune temperature/alpha on validation data, not test.

## One-batch PyTorch loss

```python
import torch
import torch.nn.functional as F
teacher_logits = torch.tensor([[4.0, 1.0, 0.0]])
student_logits = torch.tensor([[2.0, 1.5, 0.2]], requires_grad=True)
labels = torch.tensor([0])
T, alpha = 2.0, 0.5
with torch.no_grad():
    teacher_probabilities = F.softmax(teacher_logits / T, dim=1)
student_log_probabilities = F.log_softmax(student_logits / T, dim=1)
kl = F.kl_div(student_log_probabilities, teacher_probabilities, reduction="batchmean")
ce = F.cross_entropy(student_logits, labels)
total = alpha * ce + (1 - alpha) * (T ** 2) * kl
print(teacher_probabilities, ce.item(), kl.item(), total.item())
total.backward()
print(student_logits.grad)
```

The displayed scalars are generated by this code, not fixed textbook results. Teacher inference is in `no_grad`, so there is no teacher gradient graph. Teacher parameters should also have `requires_grad_(False)` and the teacher stays in `eval()` mode. Student logits remain differentiable; both CE and KL contribute to their gradients.

## Failure modes

Distillation can hurt when the teacher is inaccurate or miscalibrated, student capacity is too small, temperature/alpha is poor, the teacher/student class order differs, or teacher predictions are computed on mismatched preprocessing. Compare against label-only training with matched architecture, optimizer, epochs, augmentations, and seed protocol. If KD dominates, inspect CE/KL magnitudes and validation behavior; do not choose settings by test score.
